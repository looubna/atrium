# The one-to-one interview room

The uncropped 1080p takes as Veo delivered them, and the room photograph they were filmed from.
`public/video/inperson/room/one/` ships a 2x crop of these (`crop=960:540:480:231,scale=1920:1080`),
because the full room read as distant. Kept here so the framing can be changed without paying for
the footage again — they are not served to the app.

    landscape_master.mp4       the room listening: she writes a note and looks back up
    landscape_lead_master.mp4  the lead talking
    room_16x9.jpg              the photograph both were filmed from

See `docs/meeting-video.md` for the prompts, the safety-filter behaviour and the checks a take has
to pass before it ships.
